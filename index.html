Publicera till GitHub

Publicera anläggningar, ansvariga, relationer, transportörer och anteckningar till Nickeh1/OLS-karta. Färger följer inte med.

Uppgifterna blir läsbara för alla om GitHub-repot är offentligt, även anteckningar. Kollegorna hämtar dem när de öppnar eller uppdaterar kartan.

Token används bara för detta publiceringsförsök. Den sparas inte i filer, export eller webbläsarlagring. Välj endast repot OLS-karta och Contents: Read and write i GitHub.
